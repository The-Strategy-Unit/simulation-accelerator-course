# Simulation Accelerator Repository
This repository holds all content connected to the simulation accelerator.

## What is the Simulation Accelerator?
A programme for ICB analysts starting their simulation journey, building the foundational skills to apply this approach in practice. Some coding experience is expected (see prerequisites), along with enthusiasm to learn.

It runs as a flipped classroom. You’ll work through learning material at your own pace before each session, then use session time with tutors for discussion, problem-solving, and going deeper.

## Where do I start?

For a quick introduction to the course see our [Welcome Document](https://github.com/The-Strategy-Unit/simulation-accelerator-course/tree/main/Introduction).

During this course we are going to focus most of our learning on a specific problem. This will help you to connect each new learning component to a context everyone on the course understands and can discuss. The skills you learn will be transferable to your own simulation-based problems which you are encouraged to explore throughout your learning journey. 

By the end of this course you will:
- Understand the building blocks of simulation
- Have built a simulation model based on a real-world problem
- Have built a conceptual model based on a problem of your choice that you want to tackle using simulation (This is your capstone project).
